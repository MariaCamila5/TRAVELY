# TRAVELY

TRAVELY es una plataforma web diseñada para facilitar la planificación y gestión de experiencias de viaje.

## Objetivo

Desarrollar una plataforma que permita centralizar la información de los viajes, incluyendo destinos, itinerarios, actividades, alojamiento, transporte y gastos, facilitando la organización y el control del presupuesto.

## Tecnologías

- Visual Studio Code
- Git y GitHub
- SQL Server

## Estado del proyecto

Actualmente se encuentra en la etapa inicial de desarrollo, con la base de datos diseñada y creada en SQL Server.
